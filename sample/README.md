# sample/ — synthetic walkthrough workdir

Everything in this folder is **invented**: a fake paper ("XQ-7" is not a real
material), fake numbers, and figures drawn by `make_figures.py`. It exists so a
fresh clone can exercise the whole pipeline without touching any real paper — the
public repository must stay free of literature content.

## Run it

```bash
# 1. no ppt-master needed: validates content.json, renders SVGs + notes
python pipeline/run_pipeline.py sample --dry-run

# 2. full chain (needs PPTMASTER_DIR): gate -> export -> postproc -> verify
python pipeline/run_pipeline.py sample --name demo
```

The dry run writes to `sample/.dryrun/` (git-ignored) and uses the approximate
width model, so its deck is **not deliverable** — it only proves that the content
file and the generator agree.

The full run writes `../output/demo_逐图精讲.pptx` relative to `sample/`
(i.e. `output/` at the repo root).

## What to look at

| file | why |
|---|---|
| `content.json` | the authoring shape: `paper` + `figures`, 2 figures + 1 table, one body long enough to auto-split into a （续）page |
| `images/*.jpg` | generated by `make_figures.py`; regenerate with `python sample/make_figures.py sample/images` |
| `../pipeline/content_rules.md` | *how* to write the bodies (claim–evidence chain, three argumentative layers) |

## Regenerating the figures

```bash
python sample/make_figures.py sample/images
```

Needs Pillow only. The script draws bars, decay curves and a fake paper header —
no third-party image, no real data.
